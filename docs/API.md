# API сервиса ManagerDataBase

HTTP-обёртка (`service/api.py`) над ядром ManagerDataBase, построенная на
**FastAPI**. Сервис является модулем платформы **ReportPalette**: контракт
модуля — это `GET /health`, `GET /manifest` и рабочие эндпоинты, объявленные
в `module.json`.

Базовый URL: `http://<хост>:8000` (порт задаётся в `module.json → api.port`).

Интерактивная документация OpenAPI доступна автоматически:

* Swagger UI — `http://<хост>:8000/docs`
* ReDoc — `http://<хост>:8000/redoc`
* OpenAPI JSON — `http://<хост>:8000/openapi.json`

## Общие сведения

### Блокировка задач

Все «тяжёлые» задачи (`/run`, `/annual_plan`, `/queue_management`,
`/sz_notifications`) выполняются под одним мьютексом: одновременный запуск
двух обработок не допускается. Если задача уже выполняется, сервер отвечает:

```
409 Conflict — "Уже выполняется другая задача, попробуйте позже"
```

### Коды ошибок

| Код | Когда возвращается |
|-----|-------------------|
| 400 | Некорректный запрос: неизвестная `program`, пустой список ДСЕ, файл/лист не найдены, пустой столбец |
| 404 | `module.json` не найден в контейнере (для `/manifest`) |
| 409 | Уже выполняется другая задача |
| 500 | Внутренняя ошибка обработки (`"Ошибка при обработке: ..."`) |

## Служебные эндпоинты

### `GET /health`

Проверка живости модуля (используется Docker `HEALTHCHECK` и ReportPalette).

Ответ:

```json
{
  "status": "ok",
  "module": "managerdatabase",
  "version": "v0.5.3"
}
```

Версия берётся из переменной окружения `MODULE_VERSION` (проставляется
Docker-сборкой из git-тега релиза); при локальном запуске — `"dev"`.

### `GET /manifest`

Возвращает содержимое `module.json` из корня репозитория — манифест модуля
для ReportPalette (название, версия, команды UI, эндпоинты).

## Рабочие эндпоинты

### `POST /run` — обработка списка ДСЕ отчётами 1010 / 2012

Тело запроса (`RunRequest`):

```json
{
  "program": 1010,
  "dse_list": ["ЛТИЯ.716713.001", "ЛТИЯ.716713.002"],
  "save_input": 0,
  "max_threads": 6
}
```

| Поле | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `program` | int | — (обязательно) | Отчёт: `1010` или `2012` |
| `dse_list` | string[] | `[]` | Список ДСЕ; не может быть пустым |
| `save_input` | int | `0` | `1` — сохранить результат в `result_manager_database_reports.xlsx` |
| `max_threads` | int | `6` | Параллельность обработки (от 1 до 16) |

Обработка идёт «волной»: для каждого ДСЕ создаётся изолированный экземпляр
обработчика отчёта, задачи выполняются в пуле потоков
(`ThreadPoolExecutor`).

Ответ:

```json
{"status": "done", "program": 1010, "processed": 2}
```

Ошибки: `400` — если `program` не 1010/2012 (для файловых программ используйте
`/annual_plan`, `/queue_management`, `/sz_notifications`) или пуст `dse_list`.

### `POST /annual_plan` — загрузка годового отчёта (программа 365)

Тело запроса (`ExcelJobRequest`):

```json
{"path_to_excel_file": "/data/input/annual_plan.xlsx"}
```

Путь проверяется на существование (`400`, если файл не найден). Результат
записывается в общую SQLite-базу.

Ответ: `{"status": "done", "program": 365}`

### `POST /queue_management` — УП по очередям (программа 3)

Тело запроса: `ExcelJobRequest` (как выше). Дополнительно результат выгружается
в лист `QM <дд.мм.гггг>` файла `result_manager_database_reports.xlsx`.

Ответ: `{"status": "done", "program": 3}`

### `POST /sz_notifications` — ДСЕ по СЗ и извещениям (программа 4)

Тело запроса: `ExcelJobRequest` (как выше). Полуавтоматическое обновление
отчёта по списку файлов из Excel.

Ответ: `{"status": "done", "program": 4}`

## Эндпоинты чтения Excel

Используются интерфейсом ReportPalette для выбора листа/столбца с ДСЕ
(команды `report_1010_excel`, `report_2012_excel`). Пути нормализуются
(снятие кавычек/пробелов) и проверяются на существование.

### `POST /excel/sheets`

```json
{"path": "/data/input/list.xlsx"}
```

Ответ: `{"sheets": ["Лист1", "Лист2", ...]}`

### `POST /excel/columns`

```json
{"path": "/data/input/list.xlsx", "sheet": "Лист1"}
```

Ответ:

```json
{
  "columns": [
    {"index": 1, "name": "ДСЕ"},
    {"index": 2, "name": "Столбец 2"}
  ]
}
```

Пустые заголовки заменяются на `Столбец N`. Нумерация столбцов — с 1.

### `POST /excel/dse_column`

```json
{"path": "/data/input/list.xlsx", "sheet": "Лист1", "column_index": 1}
```

Возвращает очищенный список ДСЕ из выбранного столбца: без пустых значений и
без повторов (с сохранением порядка).

Ответ:

```json
{"dse_list": ["ЛТИЯ.716713.001", "..."], "count": 42}
```

Ошибки: `400` — файл не найден или в столбце нет значений.

Типовой сценарий (цепочка вызовов из UI):

```
POST /excel/sheets      -> выбрать лист
POST /excel/columns     -> выбрать столбец (index)
POST /excel/dse_column  -> получить dse_list
POST /run               {"program": 1010, "dse_list": [...]}
```
